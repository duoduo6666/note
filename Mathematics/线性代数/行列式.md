行列式给一个方阵对应一个**标量值**
用来描述这个矩阵的一些重要性质，比如是否可逆、空间缩放比例等

## $n$阶行列式
有$n^2$个数，排成$n$行$n$列的数表
按行定义，是$n!$项的和，每一项是$n$个元素的乘积
行标顺序排列，**列标取$n$元排列的所有可能**
**正负由列标排列的奇偶性决定**
$$\sum_{p_1p_2\cdots p_n\in S_n}\left ( -1 \right ) ^{t\left ( p_1p_2\cdots p_n \right )}a_{1p_1}a_{2p_2}\cdots a_{np_n}$$
> [!info] 原始定义
> 每项正负由$行标逆序数+列标逆序数$的奇偶性决定
> $$\sum\left ( -1 \right ) ^{t\left ( q_1q_2\cdots q_n \right )+t\left ( p_1p_2\cdots p_n \right )}a_{q_1p_1}a_{q_2p_2}\cdots a_{q_np_n}$$
