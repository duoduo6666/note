### 匀变速直线运动
| 名字       | 公式                            | 描述  |
| -------- | ----------------------------- | --- |
| **速度**   | $v=v_0+at$                    |     |
| **位移**   | $s=v_0t+\frac{1}{2}at^2$      |     |
| **速度平方** | $v_t^2-v_0^2=2as$             |     |
| **平均速度** | $\bar{v} = \frac{v_0 + v}{2}$ |     |
### 周期运动
| 名字        | 公式                                                   | 描述  |
| --------- | ---------------------------------------------------- | --- |
| **线速度**   | $v=\frac{\Delta s}{\Delta t}=\omega r$               |     |
| **角速度**   | $\omega=\frac{\Delta\theta }{\Delta t}$              |     |
| **周期**    | $T=\frac{2\pi}{\omega}=\frac{2\pi r}{v}$             |     |
| **频率**    | $f=n=\frac{1}{T}$                                    |     |
| **向心力**   | $F_n=m\frac{v^2}{r}=m\omega^2r=m\frac{4\pi^2}{T^2}r$ |     |
| **向心加速度** | $a_n=\frac{v^2}{r}=\omega^2r=\frac{4\pi^2}{T^2}r$    |     |
| **单摆周期**  | $T=2\pi\sqrt{\frac{l}{g}}$                           |     |
### 功和能
| 名字       | 公式                                      | 描述  |
| -------- | --------------------------------------- | --- |
| **功**    | $W=Fl\cos\theta$                        |     |
| **功率**   | $P=\frac{W}{t}$                         |     |
| **动能**   | $E_k=\frac{1}{2}mv^2$                   |     |
| **动能定理** | $W=\frac{1}{2}mv_1^2-\frac{1}{2}mv_0^2$ |     |
| **重力势能** | $E_p=mgh$                               |     |
| **重力做功** | $W_{AB}=E_{pA}-E_{pB}$                  |     |
| **机械能**  | $E=E_k+E_p$                             |     |
